# Opendevhub Website
Full-stack developer portfolio and open-source project platform using AngularJS, Node.js, Express.js, and MongoDB.

OpenDevHub is a dynamic web application designed as a platform for developers to showcase their projects, maintain a developer profile, and share projects that are open to public collaboration.

The project was developed as a full-stack web application using an AngularJS client, Node.js/Express.js server, and MongoDB database. It demonstrates asynchronous communication between the client and server, database-driven content, user accounts, and dynamic page rendering.

# Features
Public website

Visitors can access the site without creating an account and:

- View information about the OpenDevHub platform.
- View community statistics.
- Browse publicly visible projects.
- View project descriptions, owners, statuses, and technologies.
- User accounts.

 Registered users can:

- Log in using a username and password.
- Create a new account.
- Receive feedback for invalid login credentials.
- View their developer profile.
- Update their profile information.
- Log out of their account.
- Developer profiles.

Each user can maintain information including:

- Username
- Name
- Email
- Current position/title
- Biography
- Skills
- Project management

Authenticated users can:

- Create projects
- Add project descriptions
- Specify project status
- Specify project visibility
- List technologies used
- View their projects from their personal dashboard

Projects can be designated as Public or Private, allowing users to control which projects are displayed on the public-facing portions of the website.
